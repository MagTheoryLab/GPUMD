``nep.txt``
===========

This file contains the parameters of the :term:`NEP` model generated by the training.
It can be used by the ``gpumd`` executable to run :term:`MD` simulations. 

Spin models start with ``nep4_spin2`` or ``nep4_spin2_zbl``. The following
``spin_mode 2 <count>`` record gives the exact number of spin-header records
that follow. The counted header stores the fitted per-type spin baseline,
descriptor shape and scaler, and optional ``spin_dof_type``/``spin_env_type``
masks. Users should not edit the count or numeric payload manually.
